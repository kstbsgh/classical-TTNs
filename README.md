# Forgoing the tree structure for matrix product state structure

The primary goal is to perform the handshake between the algorithm and the MultiSiteOperator,
so that I can implement the Hamiltonian not as a full matrix but run the algorithm term by term. 

A MPS structure, with its reduced complexity would be a good testing ground to integrate the two. 

I am also trimming any method that is not needed, or is obsolete, along with blocks of code that I have commented out.

There is a lot that can be removed since I wrote large parts of this codebase without using a VCS.
